# T06 Journal and tags implementation plan

> Use superpowers:executing-plans to implement this plan inline.

**Goal:** Offline journals with optional title, required body, occurrence time, reusable tags, detail, edit and delete.

**Architecture:** Extend the existing domain record and Room v1 graph. Targeted transactional writes preserve unrelated links. Navigation-scoped SavedStateHandle drafts retain text and capture identity; Today and daily Timeline show typed journal previews.

**Tech Stack:** Existing Kotlin, Room, Coroutines, Compose and JUnit; no new dependencies.

**Spec:** TASKS.md T06 and ARCHITECTURE.md.

## Global constraints
- Native Android; domain remains free of Android/Room types.
- No network, account, runtime permission, schema migration, or future task features.
- Retain original journal body whitespace; reject blank bodies. Trim optional titles and tag names, normalize tags with Locale.ROOT.
- Tag creation and journal changes commit together; stable capture IDs make retries idempotent.

## Review focus
- Restored or ambiguously committed drafts never create duplicates or lose new text.
- Case and surrounding whitespace reuse the existing tag identity.
- Invalid tags or missing/imported journals cannot cause partial writes.
- Editing preserves child ID, audit creation time, metadata, memory and other links.
- Cancel/back and failed operations retain draft text until explicit discard or successful save.
