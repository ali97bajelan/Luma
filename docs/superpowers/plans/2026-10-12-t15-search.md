# Simple local lookup implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Offline lookup by titles, tags, people, places and dates, with fast bounded pages.

**Architecture:** Pure domain query/page/catalog models; parameterized Room SQL predicates; a lifecycle-aware saved SearchViewModel and Compose route reached from Timeline. Reuse source routes and the current version 2 database.

**Tech Stack:** Existing Kotlin, Coroutines, Room and Compose dependencies.

**Spec:** `docs/superpowers/specs/2026-10-12-t15-search-design.md` (approved by the user).

## Global constraints

- No body/note, mood/emotion or event-type search, FTS, migration or new dependencies.
- Literal substring text, AND between filter categories, OR within selected tags/people.
- 200 text characters, 100 IDs/category, 50-row pages, at most 300 retained rows.
- Typing debounce 300 ms; SQL filtering before paging; no whole-history reads.
- Preserve prior uncommitted changes and validate with an isolated app ID.

## Review focus

- A late cancelled query must never appear beneath changed filters.
- Deleted catalog selections must remain explicit rather than broaden results.
- Paging after source deletion must not append mismatched snapshots.
- Escaped wildcard input must remain literal for Persian and ASCII titles/names.
- From/Through dates must handle civil-day boundaries and invalid ranges.
