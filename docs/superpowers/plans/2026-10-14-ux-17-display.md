# Duration and List Ordering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Use consistent duration precision and visible chronological-order labels across related browsing surfaces.

**Architecture:** Introduce a pure integer duration projection with localized Compose renderers; delegate existing duration wrappers to it. Preserve query order and latest-memory selection; label lists where they already differ.

**Tech Stack:** Kotlin, Compose resources, NumberFormat, JUnit 4, Compose instrumentation; existing Room order/paging.

**Spec:** [UX 17 design](../specs/2026-10-14-ux-17-display-design.md).

**Status:** Implementation complete on working tree at HEAD `b52b9a7`. Unit tests, debug app/test APK builds and lint pass; 45 affected isolated-emulator tests pass. Manual acceptance remains pending; no commit was requested.
