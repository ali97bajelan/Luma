# T11 Complete Life Timeline Implementation Plan

Goal: a dedicated fast day timeline that merges stored manual/imported events, shows their real typed values, and opens appropriate details/editors.
Spec: TASKS.md T11 and ARCHITECTURE.md/product definition v0.1.
Architecture: domain TimelineRepository provides committed offset pages and invalidations without Android types. Room uses indexed day bounds, ORDER BY occurred_at,id, LIMIT/OFFSET plus a same-transaction count. App TimelineViewModel maintains an offset window (initial150, page50, max300) and reloads it after invalidation. LazyColumn uses stable record IDs, automatic later-page loading near its end, and explicit earlier/later controls. Date switches cancel old reads and reset the window. Existing Today remains its daily summary feed.
Constraints: API28/35, AGP8.7.3, Kotlin2.2.10, Room2.8.5; no schema migration, integration adapters, permissions, network behavior, commits/branches or emulator execution. Work in shared checkout as in preceding tasks; preserve untracked schemas/older plans.

Review focus:
- Equal timestamps must order UUIDs consistently across pages; counts/pages share one committed graph.
- Date/timezone switches reset window and scroll; skipped civil days show empty, DST uses real day bounds.
- Typed/catalog changes invalidate pages, including after returning from editors; late/failed loads retain retry and cancellation.
- Refresh after eviction uses absolute offsets; deleting records beyond an old anchor recenters without looping; prepend handles partial first pages.
- Imported/incomplete events open read-only details, missing records have a distinct state; no fabricated health/usage values.

- [x] Shared EventCard/date controls, dedicated TimelineRoute and lifecycle-aware generic detail; route manual supported records to their editors and others to read-only detail, including Today fallback. Compile mixed Timeline/device-navigation/scroll tests.
- [x] JVM/debug/test APK/data lint checks, full app lint attempt, independent read-only review, docs/status with device/performance checks pending.
