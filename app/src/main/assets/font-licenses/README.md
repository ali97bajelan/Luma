Newsreader uses weight and optical-size axes; the other fonts use weight.
Compose selects explicit bundled weights. Persian appearance uses Vazirmatn
for headings and body; Latin/French appearance uses Newsreader headings and
Plus Jakarta Sans body/controls, with Android's offline missing-glyph fallback.
Font file hashes and sampled coverage are recorded in the T30 source audit.
